# Academy Workshops — Design Challenge

Spend about **30 minutes** designing a solution. **Do not write code yet.**

## The situation

An academy organises two types of workshops: **classroom** and **online**. Each student has a name, email, and city. Each workshop has a title and a maximum number of participants. Classroom workshops also have a room, while online workshops have a meeting link.

A student can register for several workshops, but only once for each workshop. When a workshop is full, no more students can register. Cancelling a registration makes a place available again, but does not remove the student from the academy.

The academy wants to list the participants in each workshop, search for students by name, and count a workshop’s participants by city. Student details may change. For example, if a student moves to another city, future participant lists and city counts should reflect that change.

## Your task

Sketch a design and consider these questions:

- Which classes do you need, and what should each class be responsible for?
- How are the objects connected?
- Which collections would you use to store the data, and why?
- How should the system respond when a student tries to register for a full workshop?

Draw a simple **UML class diagram** to show your classes and their relationships. You can also add a **use case diagram** to show what users can do. A few boxes, arrows, and notes are enough.

Be ready to briefly explain your design. You will receive the implementation assignment afterwards.
